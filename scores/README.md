# 曲谱库

共 **33 个曲目条目，62 份不同内容的 GS2 文件**。默认曲库 33 份，另保留 29 份历史版本；完全相同的副本按 SHA-256 去重。

## 使用

从 [v3.4.1 下载页面](https://github.com/wycwysgs/yuanqin-converter/releases/tag/v3.4.1) 选择：

- `yuanqin-toolbox-with-scores-v3.4.1.zip`：程序与全部曲谱，解压后双击程序；默认自动加载旁边“曲谱”文件夹。
- `yuanqin-scores.zip`：仅曲谱。将其中的“曲谱”文件夹放在 EXE 旁边，重启程序即可自动加载。

源码运行时，先用“添加文件夹”选择本目录下的“曲谱”。也可把 GS2 复制到 BetterGI 的 `YuanQinAssistant/assets/score`，刷新助手曲库。

默认曲库的文件名不带两排/三排标记。演奏时勾选“三排模式”，取消则折回为两排。历史版本按原文件保存，需要时手动添加；原本只有两排音域的谱子无法还原丢失的低音。

原始 GS2 内容与作者署名保持不变；仅默认曲库的文件名经过整理。不同编配仍分别保留，如 Nevada 完整 MIDI、图片简谱近似版，以及不同的 See You Again 编配。
