原琴工具箱 3.4 · 转换、试听与悬浮演奏

这次更新
- 主窗口与游戏悬浮窗统一使用深蓝与青绿色主题，增加专属音符图标。
- 转换队列、导出、歌曲设置、曲库、演奏设置分别分区；转换与播放主按钮更醒目。
- 字体、输入框、曲谱选中效果和进度条统一；次要提示采用柔和文字色，停止按钮单独标色。
- 主窗口内容可滚动，悬浮窗保留紧凑布局，小窗口也能查看开始、停止和状态提示。
- 自动记住两排/三排、演奏速度、倒计时、连播、快捷键、助手目录、转换设置、曲库和悬浮窗位置。
- 主窗口和悬浮窗新增“试听前20秒”“停止试听”“测试琴键 A”。
- 新增完整伴奏、简化伴奏、主旋律三种转换模式，默认完整伴奏。
- 自动推荐移调改为按实际音符时长加权，并显示白键适配率；CSV 记录简化数量和适配率。
- 程序每次启动默认请求管理员权限，Windows 出现提示时点击“是”即可，无需再手动“管理员重开”。
- 每首 MIDI 生成一份通用 GS2，曲名不再添加“两排琴键版／三排诗琴版”。
- 主窗口和悬浮窗都有“三排模式”勾选项，两处同步。
- 勾选：使用 QWERTYU / ASDFGHJ / ZXCVBNM 三排；不勾选：使用前两排。
- 两排模式会将 Z–M 低音提高一个八度，映射到 A–J；同一时刻的重复琴键会合并。
- 切换模式不修改曲谱。请先停止演奏，再切换模式并重新开始。
- 首次默认勾选三排模式；以后恢复上次保存的选择。
- 旧文件名中的排数标记在列表中隐藏；同名两排、三排版本合并为一首，优先使用三排源文件。
- 不同编曲标记仍保留，如“合奏版”“原琴版”。同名输出的编号也保留，避免覆盖。
- 原有 MIDI、GS2 文件保留，不重命名、不删除。旧两排曲谱已经折回的低音无法还原，建议重新转换 MIDI。

开始使用
1. 关闭旧版窗口，双击桌面“原琴转换器”或“原琴播放器”，在 Windows 权限提示中点击“是”。
2. 悬浮窗可搜索、选择曲谱。按乐器勾选或取消“三排模式”。
3. 原神使用窗口或无边框模式，打开乐器演奏界面，关闭聊天框。
4. 点击“开始 / 继续”，程序请求切回原神，默认倒计时3秒后开始。
5. 默认 F8 开始 / 暂停，F9 停止；也可以使用悬浮窗按钮。
6. 切出游戏或按住 Ctrl / Alt / Shift / Windows 等修饰键时会自动暂停。
7. 点“开始 / 继续”切回游戏后恢复；停止后再次开始会从曲首演奏。

试听和琴键自检
- 选曲后点“试听前20秒”，用本机合成音色试听，不依赖游戏，也不会发送按键。
- 试听从第一个音符开始，跟随两排/三排选择及演奏速度；最长20秒，结束后有短暂的音色衰减。
- 合成音色用于检查旋律、节奏与简化效果，不等同于游戏乐器音色。
- 再次点击试听可重新生成；“停止试听”立即取消。开始游戏演奏、自检或退出也会停止试听。
- 悬浮窗“测试琴键 A”先请求切回原神，倒计时3秒后只按一次 A，无需加载曲谱。
- 使用主窗口的测试按钮时，在3秒倒计时内自行切回游戏。测试前先打开乐器界面、关闭聊天框。
- 听到琴声说明游戏收到琴键；程序不会自动判断是否发声。检查仍受前台窗口和权限限制。
- 测试期间可点击停止或按停止快捷键；测试未完成前不能开始另一首曲谱。

设置记忆
- 设置保存到 %LOCALAPPDATA%/YuanQinToolbox/settings.json，修改后约0.7秒自动保存，退出时也保存。
- 记住添加的曲谱、额外曲库文件夹与上次选曲。重开后重新扫描已记住的文件夹，缺失曲谱会略过。
- 不保存尚未转换的 MIDI 队列及逐首临时编辑；这些歌曲仍需重新添加。
- 快捷键重开时会重新注册；被其他程序占用时会提示，可更换或使用悬浮按钮。
- 设置损坏时使用默认值；读取和保存失败原因写入运行日志。

批量转换
1. 点悬浮窗“打开工具箱”，在“MIDI 转换”页添加文件，可 Ctrl / Shift 多选或添加整个文件夹。
2. 可逐首调整轨道、曲名、手动移调；转换会处理整个队列。
   伴奏模式应用于整批歌曲：完整伴奏保留所选轨道；简化伴奏每组最多保留低、中、高3音；主旋律每组只取最高音。
   分组以开始时间相差不超过30毫秒为准。主旋律是最高音启发式选择，无法保证每首歌曲都能准确识别人声旋律。
3. 点击“转换并加入曲库”，保存到程序旁的“曲谱”文件夹，并自动加入列表。
4. “批量安装到助手”保存到下方 BetterGI 目录；“批量另存”可以选择其他文件夹。
5. 转换不再选择排数，演奏时用“三排模式”切换。
6. 同名输出自动编号；单个文件失败会继续处理后续歌曲，CSV 保存详细结果。

默认助手目录
C:/Program Files/BetterGI/User/JsScript/YuanQinAssistant/assets/score
程序启动时读取该目录及程序旁“曲谱”目录已有的 GS2。
“三排模式”仅控制本工具箱的独立演奏。在 BetterGI 内播放时使用 BetterGI 的设置。
本程序独立演奏不需要启动 BetterGI；请避免同时运行其他弹琴程序。

转换设置
默认去除 MIDI 通道10的鼓轨，按每首所选轨道自动推荐移调。
关闭“每首自动推荐移调”可逐首填写 -24 至24半音。
速度、半音处理应用到整批歌曲；超出音域按八度折回。
音域折回和半音修正可能改变局部音高或和声，可试听后调整。
支持 MIDI Type0/1；不直接识别 MP3 或图片，不支持 Type2、SMPTE。
演奏速度1按曲谱保存的速度播放；转换时已调整速度后，通常保持演奏速度1。
默认只演奏选中歌曲；勾选连播可依次演奏整个列表。
转换期间不能开始演奏，演奏及暂停时请先停止再转换。

悬浮窗和权限
拖动标题栏移动；“收起主窗口”保留悬浮窗。
关闭悬浮窗会回到主窗口，主窗口可以重新打开悬浮窗；关闭主窗口退出程序。
外部置顶窗口可能无法显示在独占全屏之上，请使用窗口或无边框模式。
“检查状态”检查原神窗口及权限。普通权限程序无法向管理员权限游戏发送模拟输入。
打包程序已设置 requireAdministrator，直接打开 EXE 和使用两个桌面快捷方式都会请求管理员权限。
Windows 的系统确认仍需你自行操作；取消权限提示则本次不会启动。
通过 Python 源码启动时，如出现权限不足，仍可点击“管理员重开”。
管理员重开会重新载入已保存曲谱和通用设置；未转换的 MIDI 队列及逐首临时编辑不会恢复。
程序只检查前台是否为 YuanShen.exe / GenshinImpact.exe，不能判断乐器界面是否打开。
快捷键被占用时可在主窗口更换 F6–F11 的键并应用，或使用悬浮窗按钮。
程序旁“原琴运行日志.txt”保存状态和错误。
